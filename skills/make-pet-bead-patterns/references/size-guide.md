# Size and color guide

For 5 mm beads, physical width equals grid width × 5 mm.

| Grid | Width | Suggested maximum colors | Typical use |
|---|---:|---:|---|
| 15×15 | 7.5 cm | 5 | Minimal icon; strongest features only |
| 20×20 | 10 cm | 6 | Small ornament or coaster |
| 25×25 | 12.5 cm | 7 | Compact portrait |
| 30×30 | 15 cm | 8 | Recommended small portrait |
| 40×40 | 20 cm | 10 | Better facial detail |
| 56 columns | 28 cm | 12 | Detailed portrait |

Use exact square sizes when the user names both dimensions. Preserve the source aspect ratio only when the user supplies a single width.

For 2.6 mm mini beads, multiply the grid dimension by 2.6 mm instead. The bundled palette matching remains color-based, but confirm the user's physical bead series before claiming purchase compatibility.
